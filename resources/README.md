# Shared resources

Reference material for **any** agent working in **any** project — style
guides, checklists, reusable reference docs. This is different from a
project's own `projects/<slug>/resources/`, which holds inputs for that
one project only. Anything here is fair game repo-wide.

## How to use this

Skim what's available when it's plausibly relevant, and use your
judgment about what actually applies — nothing here is a mandatory
checklist to run through on every task.

- **`writing/signs-of-ai-writing.md`** — a field guide of tics typical of
  AI-generated text (puffed-up "significance and legacy" framing, rule-of-
  three lists, empty transitions like "it's not just X, it's Y",
  overuse of em dashes/bold/headers, hedge-everything phrasing, etc.).
  Worth a skim when you're asked to write prose meant to sound like the
  user wrote it — an email, a README, an essay, a bio, a cover letter.
  Not every point applies outside Wikipedia and not everything here is
  wrong in every context (e.g. a real README often *should* have
  headers and bullet lists) — use judgment, don't mechanically avoid
  every pattern listed.

## Adding to this

If you find or are given something reusable across projects (a style
guide, a template, a reference dataset that isn't project-specific),
drop it in here under a sensible subfolder and add a line to the list
above so the next agent knows it exists.
