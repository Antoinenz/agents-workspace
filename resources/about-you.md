## How to update this file

When a project turns up something durable and genuinely reusable across
projects (not specific to that one task), add it here under the right
section, one line, present tense. Don't let this file balloon with
one-off details — if in doubt, it probably belongs in that project's own
`README.md` instead. Commit changes to this file along with whatever
else you're pushing that turn.
